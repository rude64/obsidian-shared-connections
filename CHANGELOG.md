# Changelog

## 0.3.1

- Add persistent color pickers for shared concepts and source articles.
- Default to red concepts and green articles. Matching groups still take priority.

## 0.3.0

- Add persistent Filters, Groups, Display and Forces controls.
- Add name/path/file/tag queries, exclusions, quoted phrases and OR.
- Preserve direct neighbors optionally and suppress disconnected results.
- Add group colors, directed arrows, sizes, label threshold and force sliders.

## 0.2.0

- Replace the two-column SVG diagram with an animated canvas force graph.
- Spread nodes with local repulsion, link springs and gentle centering.
- Add draggable nodes, pointer-centered zoom, background panning and Fit graph.
- Highlight neighboring nodes and edges on hover.
- Reveal labels on hover/zoom and suppress overlapping labels.
- Render the full-path article list only when expanded.
- Stop animation and disconnect observers when the view closes or the plugin unloads.

## 0.1.0

- Initial shared-concept detection and two-column preview.
